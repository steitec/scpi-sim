Privacy

The simulation runs in your browser. Commands you type and the values you see never leave your device. The page sets no cookies, uses no tracking or analytics and loads nothing from other sites. Fonts, scripts and the Python runtime all come from this server.

Server logs

Like any web server, this one records technical data for each request: IP address, time, requested file, status code, browser identification (user agent) and referrer. These logs keep the service running and secure, for example by automatically blocking addresses that attack the server. The legal basis is the operator's legitimate interest in a secure service (Art. 6(1)(f) GDPR). The logs are not analysed for any other purpose, not combined with other data and not shared. They are deleted after [NPM log retention – filled in Task 6].
